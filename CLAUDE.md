# Birru's Space: notes for Claude

Akhil's personal portfolio. Requests usually come from the Claude mobile app, so finish the job without asking.

## Where things are
- `site/index.html`: the whole main page (HTML, CSS and JS in one file). Most edits go here.
- `site/study/index.html` is generated: edit `study/` and run `./build.sh` instead.
- `site/Akhil_Birru_Resume.pdf` is generated by `resume/build_public.py` (needs python-docx + LibreOffice).

## Shipping a change
1. Edit, then run `./build.sh --check` (must pass).
2. Commit to `main` and push. The VM pulls `main` every 5 minutes, so merging to main is the deploy.
   If you worked on a branch, open a PR and say it must be merged to go live.

## Rules
- The repo and site are public. Never add a phone number, salary/CTC, notice period, passwords, keys or `*.pem`.
- Never add code, diagrams or documents from Akhil's employer (Trustt / novopay).
- The server's Content-Security-Policy blocks every external request: no Google Fonts, CDNs, analytics or
  remote images. Use system font stacks, inline SVG, or files committed under `site/`.
  A self-hosted web font also needs `font-src 'self'` added to the CSP in `server/nginx-portfolio.conf`,
  which is installed on the VM by hand; say so in the reply when that's needed.
- Keep the 3-tap name entrance to `/study/` and the light/dark toggle working.
- Check the page at 390px width: no horizontal scroll.
